## INSTALLATION

1. Download and extract the **.zip** file.

2. Place **kdg_postal** inside your servers resources folder.

3. Ensure the resource through your **server.cfg**.

4. Restart the resource or server. 

--- 

## USAGE

**Use the following command:**

*/postal x*

*x being the postal number*
